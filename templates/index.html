How Matchy 🦾✨ Works

  • 🤖 Input: Provide two questions to analyze.
  • 🧹 Preprocessing: Cleans and standardizes the text.
  • 📊 Feature Engineering: Extracts 21 key features and scales them.
  • 🧠 Embeddings: Generates vector representations using Word2Vec.
  • 🔗 Concatenation: Combines features and embeddings into a single vector.
  • ⚡ Prediction: Uses an XGBoost model to determine duplication.
  • 🎯 Output: Displays results with a probability score.
